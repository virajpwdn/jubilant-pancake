# Virtual R

This project was built to strengthen my understanding of clean code practices and effective code structuring, with a strong focus on destructuring and the “Don’t Repeat Yourself (DRY)” principle. I learned how to organize configurations in centralized files, making it easy to add or remove items by updating a single source of truth.

I also gained hands-on experience in designing responsive grid layouts, improving both maintainability and scalability of the UI.
